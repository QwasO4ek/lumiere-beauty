# Общие сведения о проекте

- **Путь к проекту:** `c:\Users\user\Documents\project`
- **Основная цель:** Управление проектами, кодом и репозиториями пользователя.
- **Инструменты автоматизации:** GitHub CLI (`gh`), Git, OpenSSH, Antigravity Assistant.
- **Хостинг / Деплой:** Render (SSH доступ + GitHub интеграция). При запросе пользователя агент берет на себя сборку, выгрузку и хостинг сервисов.
- **Проекты в разработке:**
  1. **LUMIÈRE BEAUTY** (`c:\Users\user\Documents\project`): Премиум-салон красоты с интеллектуальной системой онлайн-записи (превосходящей DIKIDI), корзиной услуг, динамическим расчетом слотов, личным кабинетом «Мои записи», экспортом в Apple/Google Calendar и CRM-пультом расписания. Репозиторий: `https://github.com/QwasO4ek/lumiere-beauty`, сайт доступен на Render: `https://lumiere-beauty.onrender.com`.
  2. **DENTIS LUX** (`c:\Users\user\Documents\project\2`): Универсальная автоматизированная платформа цифровой стоматологии полного цикла. Включает интерактивную зубную карту FDI (32 зуба), AI-триаж симптомов с оценкой срочности и памяткой первой помощи, умную запись с генерацией `.ics` календаря и диалога WhatsApp, калькулятор лечения и рассрочки 0-0-24, слайдер «До/После», демо электронной медкарты пациента (EMR) и AI-ассистента DentoBot. Запущен локальный сервер: `http://localhost:5174`.
