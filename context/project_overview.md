# Общие сведения о проекте

- **Путь к проекту:** `c:\Users\user\Documents\project`
- **Основная цель:** Управление проектами, кодом и репозиториями пользователя.
- **Инструменты автоматизации:** GitHub CLI (`gh`), Git, OpenSSH, Antigravity Assistant.
- **Хостинг / Деплой:** Render (SSH доступ + GitHub интеграция). При запросе пользователя агент берет на себя сборку, выгрузку и хостинг сервисов.
- **Текущий проект:** Сайт-визитка премиум-класса «LUMIÈRE BEAUTY» (салон красоты в Алматы). Стек: React, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- **Текущее состояние:** Полнофункциональная платформа премиум-салона красоты с интеллектуальной системой онлайн-записи (превосходящей DIKIDI), корзиной услуг, динамическим расчетом слотов, личным кабинетом «Мои записи», экспортом в Apple/Google Calendar и CRM-пультом расписания. Код собран (`npm run build`), выгружен в GitHub (`main`) и задеплоен на Render (`https://lumiere-beauty.onrender.com`).
