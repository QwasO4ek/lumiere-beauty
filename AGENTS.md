# Инструкции и правила для агента (Antigravity / Gemini)

## Обязательное правило при начале работы:
1. **Всегда в первую очередь анализируй содержимое папки `context/`** (`./context/`):
   - Проверяй все файлы в этой папке (`project_overview.md`, `github_config.md`, `history.md` и др.), чтобы восстановить актуальный контекст проекта, статус репозиториев, учетные данные и договоренности с пользователем.
   - Используй полученные данные для принятия решений в любых последующих задачах.

## Правило сохранения важных данных:
2. **Все ключевые изменения, решения, доступы, архитектурные решения и новые сущности сохраняй и актуализируй в `context/`**:
   - При добавлении новых репозиториев, ключей, переменных окружения, зависимостей или структуры проекта — обязательно обновляй соответствующие файлы в `context/`.
   - При принятии важных решений фиксируй их в `context/history.md`.
